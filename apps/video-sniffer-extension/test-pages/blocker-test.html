Blocker test page

Each case says what should happen with Video Sniffer's blocker on. Every link and popup goes to example.com.

1. Real button opens a window

Should open. A click on a real button is allowed.

2. Real link with target=_blank

Open example.com in a new tab

Should open.

3. Delayed popup after a click

Should be blocked; the extension popup then shows "Blocked 1 on this page". Without the extension, Chrome would allow it.

4. Invisible overlay (an ad trap)

Clicks that reached the page: 0

Press "Step 1" (nothing visible changes: an invisible layer now covers the page). Press "Step 2". That first press should do nothing: no new tab, and the number stays 0. Press "Step 2" again: the number goes up to 1, because the extension switched the trap off. The extension popup now shows "Blocked 2 on this page" and "Restore overlay".

5. Normal player, no trap

Reload the page (F5) first. Then play, pause, drag the timeline and go full screen. Everything should work normally, and the extension popup should list Big_Buck_Bunny_360_10s_1MB.mp4 with its size. If the player stays black and never plays, the test video didn't load; do this check on the hls.js demo page instead.
