# Bundled libraries

The phone app ships two small libraries as files, so it works offline and pins exact versions.

- `peerjs.min.js`: PeerJS 1.5.4 (https://github.com/peers/peerjs), MIT License, Copyright (c) 2015 Michelle Bu and Eric Zhang.
  Sets up the direct device-to-device connections. By default it uses PeerJS's free public server only to introduce devices.
- `qrcode.js`: QR Code Generator for JavaScript 1.4.4 (https://github.com/kazuhikoarase/qrcode-generator), MIT License,
  Copyright (c) 2009 Kazuhiko Arase. Draws the QR codes on the phone.
